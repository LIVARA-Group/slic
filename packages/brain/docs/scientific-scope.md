# Scientific Scope

## Scientific position

The package models selected neuroanatomical structures and curated functional relationships.

It does not claim to reproduce the complete biological brain.

## Distributed functions

Cognitive functions are represented as distributed processes.

A process may involve several cortical, subcortical and peripheral structures.

The model does not assume that a single region independently performs a complex cognitive function.

## Limbic terminology

The term "limbic system" is used cautiously.

Its anatomical boundaries vary across scientific traditions.

The package treats limbic-related structures as a conceptual functional grouping.

## Sensory interfaces

The retina and cochlea are represented as sensory boundaries.

They are not classified as brain structures.

## Evidence

Evidence metadata describes the current provenance status of definitions.

An empty source list means that individual source-level provenance has not yet been attached.

Do not interpret curated status as quantitative confidence.

## Research directions

Future validation may use:

- Allen Brain Atlas.
- Human Connectome Project.
- EBRAINS.
- Uberon.
- Brodmann-related references.

Dataset integration requires explicit versioning, anatomical mapping and provenance.

## Simulation boundary

A biologically meaningful neural simulation would require a separate research and engineering effort.

It would need explicit models of:

- Neuron populations.
- Synaptic mechanisms.
- Time dynamics.
- Parameter sources.
- Calibration.
- Validation datasets.
- Computational performance.

Graph traversal must not be presented as such a simulation.
